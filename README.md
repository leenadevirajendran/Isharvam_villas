# Isharvam Villas: frontend (demo build)

Static, multi-page luxury villa website: HTML5, CSS3, vanilla JavaScript, GSAP + ScrollTrigger, Swiper and SVG. No PHP, no database, no payment gateway.
All villas, prices, availability, bookings and the admin area use **sample data** and are labelled as such on screen.

## Run it
Open `index.html` directly in a browser, or serve the folder (recommended):

    python3 -m http.server 8000      # then visit http://localhost:8000

Admin demo (no login): `admin/index.html`.

## Pages
Public (17): index, villas (explore), search, villa (detail, `?v=villa-aanya`), checkout, confirmation, login, register, my-bookings, about, experiences, contact, faq, privacy, terms, cancellation, 404.
Admin (10): dashboard, villas, villa-edit, gallery, pricing, availability, bookings, guests, payments, reports and settings.

## How booking works (no payment on the website)
Guest picks dates, sends a **booking request**, and is handed to the owner's WhatsApp with a prefilled message. Payment is arranged there. Requests are stored in the browser (localStorage) so My bookings and the admin demo can show them. Demo requests are clearly labelled as not real.

## Where to change things
- Contact details, WhatsApp number, fees, tax, check-in/out times: `assets/js/config.js`
- Villas, locations, amenities, FAQs, sample bookings: `assets/js/mock-data.js` (generated by `tools/gen_data.py` from `tools/roster.py`; you can also edit the JS directly)
- Images: `assets/img/villas/` and `assets/img/site/`. Paths are centralised in config and `ISH.img()`. Missing images fall back to `assets/img/site/fallback.webp`.
- Page source: `src/pages/*.html` with shared partials in `src/partials/`. After editing run `python3 tools/build.py` to regenerate the root and `admin/` HTML.
- Design tokens (colours, type, spacing, motion): top of `assets/css/base.css`

## Assumptions to confirm
- WhatsApp number is treated as +91 8675759131. Which phone is the main line is unconfirmed.
- **Business address not provided**: footer and contact show a labelled placeholder.
- Sample policy values: check-in 2:00 PM, check-out 11:00 AM, 1-night minimum, cleaning fee ₹2,500, 12% tax, weekend (Fri/Sat) +15%.
- Legal pages contain template placeholders only and need real text from the business.
- All villa names, locations, testimonials and descriptions are fictional placeholders. No real reviews are shown.
- Images are generated architectural illustrations (stock photo sites were not reachable while building). Replace them with real photography: same file names, WebP, plus an `-sm.webp` 800px variant.

## Photographs (temporary demo images)
Villa and site photos are free-to-use Pexels photographs, hand-matched to each villa's category and location (credits: `assets/img/CREDITS.md`). Out of the box they load from the Pexels CDN (internet needed; the old illustrations remain as a last-resort fallback). To make them local and permanent for the demo, run once on a computer with internet:

    pip install pillow
    python3 tools/fetch_photos.py

It downloads all 107 slots, converts them to WebP (2000px + 800px `-sm`) into `assets/img/`, and sets `remote:false` in `assets/js/photos.js`. All image paths stay centralised (`ISH.img()`, `config.js`); to swap in the client's own photos, drop files with the same names in `assets/img/villas|site/`. `PHOTO-PROMPTS.md` + `tools/import_photos.py` remain available if you prefer generating images.

## For the PHP/MySQL phase later
Availability, pricing and booking creation must become server-authoritative. The places to replace are marked in `assets/js/utils.js` (`ISH.isAvailable`, `ISH.quote`, `ISH.bookings`) and `assets/js/admin-core.js` (data layer).

## Accessibility and performance
Keyboard-accessible calendar, dialogs and filters; visible focus; `prefers-reduced-motion` disables scroll-scrubbed animation and shows a static lit state; self-hosted fonts and scripts; WebP images with responsive `srcset`.

## Typography
Headings: Newsreader (light, lining figures). Body and UI: Jost. Rupee sign: Newsreader latin-ext subset via the `Rupee` face. All self-hosted in assets/fonts.

## Hero illustration
The home hero is a coloured line-art villa (day to dusk to night, scroll-scrubbed). It is generated by `python3 tools/gen_hero_svg.py` (edit shapes/colours there, then run it and `python3 tools/build.py`). Colour variables for day/dusk/night live in `assets/js/home.js` (DUSK / NIGHT) and `assets/css/home.css`.
